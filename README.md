# Google Antigravity (90 Minutes)

Gemini Antigravity is an acceleration framework designed to remove friction from AI-powered development workflows. By combining Google's Gemini models with lightweight automation, Antigravity eliminates routine boilerplate, streamlines configuration, and lets developers rapidly prototype and deploy intelligent solutions with minimal cognitive overhead.

In this focused 90-minute session, you will explore the full setup and daily usage of both the Antigravity CLI and the graphical Antigravity App. Through practical live demos, you will learn step-by-step installation routines, common command patterns, and essential interface features so you can integrate both tools into your development environment immediately.
