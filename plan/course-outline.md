# Course Title: Google Antigravity (90 Minutes)

## Course Description

Gemini Antigravity is an acceleration framework designed to remove friction from AI-powered development workflows. By combining Google's Gemini models with lightweight automation, Antigravity eliminates routine boilerplate, streamlines configuration, and lets developers rapidly prototype and deploy intelligent solutions with minimal cognitive overhead.

In this focused 90-minute session, you will explore the full setup and daily usage of both the Antigravity CLI and the graphical Antigravity App. Through practical live demos, you will learn step-by-step installation routines, common command patterns, and essential interface features so you can integrate both tools into your development environment immediately.

## Learning Objectives

- Set up and use the Google Antigravity CLI and graphical App to accelerate AI-powered development workflows
- Install, authenticate, and configure the Google Antigravity framework in a local development environment
- Execute common command patterns and automate code generation tasks with the Antigravity CLI
- Navigate the graphical Antigravity App to prototype, inspect, and manage intelligent development workflows

## Who Should Attend

Developers, AI and Data Engineers, and programmers interested in learning to use Google Antigravity to improve software quality and productivity.

## Prerequisites

- Familiarity with software development, programming, and modern development environments like Visual Studio Code
